# ADR 0010 — Pilote : le collège

**Date :** 2026-09-27 · **Statut :** ✅ Acceptée (choix d'Amadou)

## Contexte

Le collège a peu de classes (1AC-G1, 1AC-G2, 2AC) ; c'est le seul niveau dont les contrôles sont déjà dans Planning Évaluations et dont l'emploi du temps est dans le périmètre lu par Planning Évaluations.

## Décision

Le pilote couvre **uniquement les familles du collège**. Primaire et préscolaire viendront après la mesure du pilote (backlog).

## Conséquences

- Le périmètre est un **paramètre** (classes incluses), pas une valeur codée en dur.
- Frères et sœurs du primaire : voir ADR 0004 (point à confirmer).
