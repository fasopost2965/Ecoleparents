# ADR 0008 — Arabe, français, anglais ; arabe par défaut

**Date :** 2026-09-27 · **Statut :** ✅ Acceptée (règle d'Amadou pour toutes les communications aux parents)

## Contexte

Parents majoritairement arabophones ; certains lisent le français, quelques-uns l'anglais. Planning Évaluations est bilingue FR/AR (son ADR 0009).

## Décision

- Espace parents en **arabe (par défaut, RTL complet)**, **français**, **anglais** ; choix mémorisé par compte (R19).
- Administration en **français uniquement**.
- Annonces : arabe obligatoire, français et anglais facultatifs, repli sur l'arabe (R16).
- Fiche d'accès : arabe et français.
- Nom de l'école : « École La Victoire, Tétouan » dans toutes les langues (le nom arabe n'est jamais utilisé dans les documents).
- **Tous les textes destinés aux familles sont validés par Amadou** avant d'être codés, dans les trois langues.

## Conséquences

- Maquettes faites d'abord en arabe.
- Polices : Noto Naskh Arabic à l'écran, XB Riyaz dans les PDF (mpdf).
